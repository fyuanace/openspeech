## 运行边界

- 设备端与服务端分别启动、停止和重启，可同机部署或后续分机部署。
- 首版设备端运行在当前 Windows 10，使用系统麦克风及音频输出。
- 默认优先千问 S2S；串联模式保留豆包 STT、DeepSeek LLM 和 Windows 本地 TTS。
- 仅要求当前模式的模型凭据，模式切换后重启服务端与设备端，建立新会话。
- 模型配置支持本地和在线适配，后续增加真实模型实现。
- openspeech 位于桌面独立目录，与 Findtools 分别管理 Git 仓库、进程和依赖，通过 MCP 接口集成。

## 部署入口与资料

| 入口 | 要求 |
| --- | --- |
| `deploy.cmd` | 一键准备 Windows 环境、依赖、配置和默认唤醒模型，再启动服务端 |
| `deploy.cmd -PrepareOnly` | 仅准备环境，不启动服务端或设备端 |
| `deploy.cmd -ServerOnly` | 服务端部署可跳过设备唤醒模型下载 |
| `setup.cmd`、`setup.ps1` | 保留原有仅准备环境入口 |
| `start-server.cmd`、`start-device.cmd` | 分别承担日常启动，不重复安装 |

- 部署保留本地配置、平台 token、模型和对话数据。失败时停止，不自动结束已有进程。
- 首次模型凭据由使用者配置；设备端在配置完成后独立启动。
- README 提供项目概览和快速开始。安装看 [部署指南](../部署指南.md)，日常操作看 [使用说明](../使用说明.md)，细节看 [运行指南](../运行指南.md)。
- 新增部署脚本当前仅完成静态检查，尚未执行部署验收。

## 调试与验收

- 使用录音样本验证连续唤醒和指令，再使用系统麦克风验证真实输入。
- 单独验证模型识别、对话、合成和播放，之后验证完整闭环。
- 接入业务系统时使用测试实例与模拟设备。
- 模型故障或语音重启时，Findtools 手动查货和亮灯仍可操作。
- 本地推理与其他进程共享硬件，资源占用和响应指标需要实测。

## 重要设计变更

- CHG-001，2026-11-04，首版部署目标明确为 Windows 10，设备端和服务端可同机独立运行，为分机部署保留边界。
- CHG-002，2026-11-04，默认部署 S2S，健康检查按模式报告缺少的配置，串联模式保留独立切换入口。
- CHG-003，2026-11-05，项目迁至桌面 openspeech 目录，Git 元数据与运行资源一并独立维护，移除对子模块和父仓库本机 origin 的依赖。
- CHG-004，2026-11-05，按公开仓库组织用户文档和贡献入口，提供一键部署脚本；安装准备与日常启停分离，保留已有配置和运行数据。脚本按用户要求暂不执行部署验证。
