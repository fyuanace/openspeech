# 部署与调试

- 更新日期为 2026-11-05。总体方向已确定，具体接口细节按正文标注。
- 当前已实现首版 Windows 音频链路与服务端适配，真实云端调用及现场效果待验证，详见[运行指南](../运行指南.md)。
- 返回[总体架构设计](总体架构设计.md)或[索引](index.md)。

## 运行边界

- 设备端与服务端分别启动、停止和重启，可同机部署或后续分机部署。
- 首版设备端运行在当前 Windows 10，使用系统麦克风及音频输出。
- 默认优先千问 S2S；串联模式保留豆包 STT、DeepSeek LLM 和 Windows 本地 TTS。
- 仅要求当前模式的模型凭据，模式切换后重启服务端与设备端，建立新会话。
- 模型配置支持本地和在线适配，后续增加真实模型实现。
- openspeech 位于桌面独立目录，与 Findtools 分别管理 Git 仓库、进程和依赖，通过 MCP 接口集成。

## 调试与验收

- 使用录音样本验证连续唤醒和指令，再使用系统麦克风验证真实输入。
- 单独验证模型识别、对话、合成和播放，之后验证完整闭环。
- 接入业务系统时使用测试实例与模拟设备。
- 模型故障或语音重启时，Findtools 手动查货和亮灯仍可操作。
- 本地推理与其他进程共享硬件，资源占用和响应指标需要实测。

## 待定项

- CHG-001，2026-11-04，首版部署目标明确为 Windows 10，设备端和服务端可同机独立运行，为分机部署保留边界。
