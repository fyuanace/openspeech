# 通用接入

- 更新日期为 2026-11-05。
- 已实现 Windows 音频接入、S2S 设备工具和外部 MCP 工具接入。Findtools 的 MCP 工具待实现。
- 返回[总体架构设计](总体架构设计.md)或[索引](index.md)。

## 职责与接口边界

| 接口 | 连接双方 | 内容 |
| --- | --- | --- |
| 设备接入 | PC、树莓派、ESP32 与服务端 | 音频输入、状态、识别文字、回复音频和会话控制 |
| 模型能力接口 | 服务端与 S2S、STT、TTS、LLM 适配器 | 统一调用及结果约定，具体技术定义由服务端维护 |
| MCP 工具接口 | 小美服务端与配置的工具提供方 | 工具发现、调用及执行结果 |
| 业务接入 | 语音平台与 Findtools 等项目 | 识别结果、可选业务请求、执行结果及回复内容 |

- 对外接口可复用，设备端与接入项目独立于具体模型提供方。
- 能力查询声明当前模式、音频规格和端点；S2S 使用流式会话接口，串联模式使用完整语句接口。
- 文本转写在 S2S 模式下属于可选能力，业务接入不能假定所有模型都返回用户转写。
- 业务执行和结果确认由接入项目负责，语音平台可把结果组织为回复并播报。
- 首版先完成 Windows 语音对话闭环，Findtools 命令范围和动作规则继续单独维护。

## 工具提供方式

| 提供方 | 调用方 | 连接方式与状态 |
| --- | --- | --- |
| 小美服务端 | 模型经由小美调用 | 已支持结束当前会话 |
| Windows MCP Server | 小美服务端作为 MCP Client | 本机 Streamable HTTP 端点提供音量工具 |
| 外部 MCP Server | 小美服务端作为 MCP Client | 可配置多个可达的 Streamable HTTP 服务，独立发现、授权和启停 |
| Findtools | 小美服务端 | 查物料与亮灯由 Findtools 执行。可通过 MCP 提供，具体工具待实现 |

- 管理员在网页填写 MCP 服务地址，发现并选择允许模型调用的工具。修改后对新会话生效。
- 小美仅将已启用的工具提供给 S2S 模型。外部服务负责执行，小美按实际结果播报。
- MCP 服务连接失败时，普通对话仍可使用。工具执行失败时反馈失败。
- 小美在公网而 Findtools 仅在仓库内网时，可由内网网关主动连小美，再沿该连接下发业务请求。网关方案待实现。

- 通过示例业务客户端验证结果关联和故障状态。
- 多设备、多项目的路由、重复投递、重连与过期请求行为需明确。
- 具体传输协议、接口版本与业务调用契约待细化。

## 重要设计变更

- CHG-001，2026-11-04，接入范围从识别文本扩展到设备音频、对话结果及回复音频，以支持设备端与服务端分离。
- CHG-002，2026-11-04，增加双模式能力查询和实时会话接口，供应商事件统一由平台适配。
- CHG-003，2026-11-04，区分平台工具、设备工具和业务工具，明确设备回调及外部业务接入方向。
- CHG-004，2026-11-05，加入可视化 MCP 接入及工具白名单，允许独立业务项目复用其工具。
- CHG-005，2026-11-05，Windows 音量工具纳入标准 MCP 接入流程。
- CHG-006，2026-11-05，支持多个 MCP 服务器及同名工具，逐台管理连接和权限。
