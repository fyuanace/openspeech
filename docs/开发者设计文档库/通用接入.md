## 职责与接口边界

| 接口 | 连接双方 | 内容 |
| --- | --- | --- |
| 设备接入 | PC、树莓派、ESP32 与服务端 | 音频输入、状态、识别文字、回复音频和会话控制 |
| 模型能力接口 | 服务端与 STT、TTS、LLM 适配器 | 统一调用及结果约定，具体技术定义由服务端维护 |
| 业务接入 | 语音平台与 Findtools 等项目 | 识别结果、可选业务请求、执行结果及回复内容 |

- 对外接口可复用，设备端与接入项目独立于具体模型提供方。
- 业务执行和结果确认由接入项目负责，语音平台可把结果组织为回复并播报。
- 首版先完成 Windows 语音对话闭环，Findtools 命令范围和动作规则继续单独维护。
