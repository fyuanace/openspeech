## 职责与接口边界

| 接口 | 连接双方 | 内容 |
| --- | --- | --- |
| 设备接入 | PC、树莓派、ESP32 与服务端 | 音频输入、状态、识别文字、回复音频和会话控制 |
| 模型能力接口 | 服务端与 S2S、STT、TTS、LLM 适配器 | 统一调用及结果约定，具体技术定义由服务端维护 |
| 设备工具接口 | 服务端与当前语音终端 | 工具声明、调用及执行结果 |
| 业务接入 | 语音平台与 Findtools 等项目 | 识别结果、可选业务请求、执行结果及回复内容 |

- 对外接口可复用，设备端与接入项目独立于具体模型提供方。
- 能力查询声明当前模式、音频规格和端点；S2S 使用流式会话接口，串联模式使用完整语句接口。
- 文本转写在 S2S 模式下属于可选能力，业务接入不能假定所有模型都返回用户转写。
- 业务执行和结果确认由接入项目负责，语音平台可把结果组织为回复并播报。
- 首版先完成 Windows 语音对话闭环，Findtools 命令范围和动作规则继续单独维护。

## 工具提供方式

| 提供方 | 调用方 | 连接方式与状态 |
| --- | --- | --- |
| 小美服务端 | 模型经由小美调用 | 已支持结束当前会话 |
| 语音终端 | 小美服务端 | 已支持沿设备主动建立的 S2S WebSocket 调用 Windows 音量工具 |
| Findtools | 小美服务端 | 首版计划由小美调用可达的 HTTP 接口，查物料与亮灯由 Findtools 执行 |

- 需要与其他 AI 客户端复用工具时，可以将能力作为 MCP 工具提供。届时提供方是 MCP Server，小美作为调用方时是 MCP Client。MCP 接入待实现。
- 小美在公网而 Findtools 仅在仓库内网时，可由内网网关主动连小美，再沿该连接下发业务请求。网关方案待实现。
