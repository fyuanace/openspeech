# 部署指南

返回 [README](../README.md) · [文档索引](index.md) · 部署后阅读 [使用说明](使用说明.md)。

## 支持范围与验证状态

- 主要路径：Windows x64，同机运行服务端和语音设备端。
- 部署入口：`deploy.cmd`；实现位于 `scripts/deploy.ps1` 与 `scripts/setup.ps1`。
- 当前脚本仅做静态检查，尚未在本机或全新系统执行部署验证。
- 脚本不运行测试，不调用云端对话接口，不自动开始麦克风监听。
- 不安装系统服务，不设置开机启动，不修改防火墙。
- 本项目使用 [PolyForm Noncommercial 1.0.0](../LICENSE)。商业用途需另行获得授权。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 x64；当前设备端以 Windows 为主要实现 |
| Python | 预先安装 Python 3.12 x64，包含 pip、venv 和 Tk 支持 |
| PowerShell | Windows PowerShell 5.1，使用系统自带入口即可 |
| 网络 | 可访问 Python 包索引、构建依赖和 Vosk 模型下载站点；语音对话还需可访问所选模型服务 |
| 麦克风与输出设备 | 运行语音设备端时需要，并允许桌面应用使用麦克风 |
| 模型账号 | 自备所选平台 API Key；使用百炼接入时还需业务空间 ID |
| Git | 可选，也可下载仓库 ZIP |
| Node.js | 普通部署不需要；管理台静态文件已随仓库提供 |

- 安装脚本使用 Python 3.12 的依赖快照。包元数据的兼容范围不代表其他 Python 版本已完成部署验证。
- 不需要管理员权限。解压到当前用户可写的目录，避免需要提权的系统目录。
- 脚本不会自动安装系统 Python。找不到解释器时会停止并提示指定路径。

## 一键部署

1. 下载仓库 ZIP 并解压，或执行：

   ```powershell
   git clone https://github.com/fyuanace/openspeech.git
   cd openspeech
   ```

2. 双击项目根目录的 `deploy.cmd`，或执行：

   ```powershell
   .\deploy.cmd
   ```

3. 等待脚本完成环境准备，再等待服务端出现 `Application startup complete`。
4. 保留该窗口，打开 [管理台](http://127.0.0.1:8765/admin)。
5. 按 [使用说明](使用说明.md) 配置模型，再运行 `start-device.cmd`。

### 脚本执行内容

| 阶段 | 行为 |
| --- | --- |
| 部署前检查 | 检查目标端口和本项目设备进程；检测到运行实例时停止部署，不结束现有进程 |
| 虚拟环境 | 在项目目录创建或复用 `.venv/`，检查 Python 3.12 x64 |
| 依赖 | 按 `requirements-lock.txt` 安装依赖，再安装本项目；失败时停止 |
| 配置 | 不存在时生成 `config.local.json`，自动生成平台连接 token；已有文件保持原样 |
| 唤醒模型 | 下载默认中文 Vosk 模型；已有默认模型目录时复用 |
| 启动 | 在当前窗口运行服务端；不自动启动语音设备端 |

- 下载和安装需要联网。脚本不依赖 Node.js，也不构建前端。
- 安装完成不代表模型账号已授权或语音闭环已通过。
- 默认服务地址为 `http://127.0.0.1:8765`。修改端口后，按 `config.local.json` 中的端口访问管理台。

## 部署参数

| 参数 | 用途 |
| --- | --- |
| `-Python "解释器完整路径"` | 新建虚拟环境时指定 Python 3.12 x64；已有环境会继续复用 |
| `-PrepareOnly` | 只准备环境，不启动服务端 |
| `-ServerOnly` | 跳过设备唤醒模型下载；仍安装统一 Python 依赖，不是精简依赖包 |

```powershell
# 找不到 py 启动器，或电脑上有多个 Python。
.\deploy.cmd -Python "C:\Python312\python.exe"

# 只安装，不运行。
.\deploy.cmd -PrepareOnly

# 服务端电脑不需要唤醒模型。
.\deploy.cmd -ServerOnly

# 只准备服务端环境。
.\deploy.cmd -PrepareOnly -ServerOnly
```

旧入口 `setup.cmd` 继续可用，只准备环境。它支持 `-Python`，并以 `-SkipModel` 跳过模型下载。

## 日常启停

部署完成后不必重复安装。

| 操作 | 方法 |
| --- | --- |
| 启动服务端 | `start-server.cmd` |
| 启动设备端 | `start-device.cmd`，同一电脑只启动一次 |
| 暂停 / 恢复监听 | 设备托盘菜单 |
| 停止设备端 | 设备托盘菜单 → 退出 |
| 停止服务端 | 服务端窗口按 `Ctrl+C` |

`deploy.cmd` 启动的服务端也在当前窗口运行。关闭窗口会结束服务，下一次可用 `start-server.cmd` 启动。

## 配置和数据

| 路径 | 内容 | 更新时 |
| --- | --- | --- |
| `config.example.json` | 无密钥配置模板 | 跟随代码更新 |
| `config.local.json` | 本地设置、模型凭据、自动生成的平台 token | 保留，并备份到私有位置 |
| `.venv/` | 本目录 Python 环境 | 可重建，不随目录迁移复制使用 |
| `models/` | 下载的本地唤醒模型 | 保留；默认模型目录存在时跳过下载 |
| `data/` | 对话日志数据库等运行数据 | 停止服务后备份、保留 |
| `logs/` | 本地调试日志目录，按运行方式使用 | 按需保留 |

- `config.local.json`、模型、环境和运行数据已被 Git 忽略。
- `.env` 被忽略，但程序不会自动读取该文件。环境变量需在启动程序的终端或系统用户环境中设置。
- 不覆盖旧配置。升级时对照示例补充新增字段，保留原有平台 token。
- `-ServerOnly` 不删除已经下载的模型。

## 分机部署

当前一键脚本以本机管理为默认。分机需要手工配置，自动设备配对尚未实现。

1. 服务端电脑运行 `deploy.cmd -ServerOnly`。
2. 在服务端电脑本机完成模型配置。
3. 将服务端 `server.host` 改为 `0.0.0.0`，停止后用 `start-server.cmd` 重启。
4. 由部署者按受信任内网范围配置端口访问。脚本不会自动开放防火墙。
5. 设备端电脑运行 `deploy.cmd -PrepareOnly`，生成自己的本地配置和模型。
6. 在设备端的本地配置中，设置不同的 `device.id`，将 `device.server_url` 指向服务端，并通过私有渠道同步服务端的 `server.token`。只同步连接所需字段，不复制服务端模型密钥。
7. 设备端运行 `start-device.cmd`。设备端电脑无需另启语音服务端。

- 管理台仅接受服务端本机访问；远程设备使用音频接口，不直接访问管理台。
- 绑定 `0.0.0.0` 时仍从服务端本机 `127.0.0.1` 打开管理台。部署脚本不直接支持仅绑定某个非回环地址的管理流程。
- 默认 HTTP 仅适用于受信任内网。跨公网需另行部署 HTTPS/WSS、访问控制与代理；本项目尚未提供自动化公网部署方案。
- Windows 串联 TTS 依赖服务端的 Windows 语音组件。Linux 服务端、容器及无桌面设备部署尚未验收。

## 更新和迁移

1. 退出语音设备端，停止服务端。
2. 私下备份 `config.local.json` 与 `data/`，按需备份 `models/`。
3. 使用 Git 的安装方式，在干净工作区执行 `git pull --ff-only origin main`。ZIP 安装时，在新目录解压新版后迁入配置和运行数据。
4. 对照 `config.example.json` 补充新增字段，再运行 `deploy.cmd -PrepareOnly` 更新环境。
5. 重新启动服务端和设备端。

- 迁移目录或电脑后重新建立 `.venv/`。如有不兼容旧环境，停止程序后将旧 `.venv/` 移出项目，再运行部署脚本。
- 不要通过删除 `config.local.json` 解决升级问题，这会丢失设置并重新生成平台 token。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到 Python，或版本不匹配 | 安装 Python 3.12 x64，使用 `-Python` 指定路径 |
| 部署提示端口被占用 | 停止已有服务。日常使用已有服务时无需重新部署 |
| 部署提示设备端正在运行 | 在托盘退出设备端，再执行部署 |
| 包安装失败 | 查看首个 pip 错误，检查网络和包索引，修复后重新部署 |
| 模型下载失败 | 检查网络后重试；可按示例配置中的路径放置完整官方模型 |
| 管理台提示待配置 | 填写当前模式的模型凭据；环境安装不会代办云端账号授权 |
| 无法录音或播放 | 检查 Windows 音频权限和默认设备，详见 [运行指南](运行指南.md#调试命令) |

## 卸载

1. 退出设备托盘，停止服务端。
2. 备份需要保留的配置、模型和对话记录。
3. 删除本项目目录即可移除本目录安装内容。

脚本不注册系统服务、计划任务或全局 Python 包。预先安装的系统 Python 由用户自行管理。
