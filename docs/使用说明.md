# 使用说明

返回 [README](../README.md) · [文档索引](index.md)。尚未安装时先看 [部署指南](部署指南.md)。

## 第一次使用

1. 运行 `start-server.cmd`。若部署脚本已启动服务端，保留原窗口即可。
2. 打开 [管理台](http://127.0.0.1:8765/admin)，进入模型配置。
3. 保持默认 S2S，选择接入平台并填写自己的模型凭据。
4. 保存后点击“测试 S2S 连接”。成功后运行 `start-device.cmd`。
5. 在 Windows 托盘找到 openspeech，等待“等待唤醒”。

| 模式 | 需要准备 |
| --- | --- |
| S2S，默认 | 千问 API Key；百炼接入还需业务空间 ID |
| 串联 | 豆包 STT 凭据、DeepSeek 或兼容 LLM 凭据、Windows 中文 TTS |

平台连接 token 由初始化自动生成。同机使用无需手工填写设备密钥。

## 语音对话

1. 连说唤醒词和内容：**“小智小智，介绍一下你自己。”**
2. 说完停顿，等待回复。
3. S2S 播报结束后可以直接追问，无需再说唤醒词。
4. 说“结束对话”，或等待追问超时，设备回到等待唤醒。

- 默认追问等待 20 秒。串联模式每轮需要重新唤醒。
- 回复处理和播放期间暂停采音，当前不支持打断播报。
- 唤醒词可以修改，详细参数见 [运行指南](运行指南.md#网页配置)。

## 日常操作

| 需要做什么 | 操作 |
| --- | --- |
| 启动 | 先运行 `start-server.cmd`，再运行 `start-device.cmd` |
| 暂时停用麦克风 | 托盘菜单 → 暂停监听 |
| 恢复使用 | 托盘菜单 → 继续监听 |
| 查看设备状态或错误 | 托盘菜单 → 交互过程 |
| 查看历史对话 | 管理台 → 对话日志 |
| 修改模型 | 管理台保存配置后，在设备托盘暂停再继续监听 |
| 退出 | 托盘菜单 → 退出；服务端窗口按 `Ctrl+C` |

同一台电脑只启动一个设备实例。托盘图标可能在任务栏折叠区中。

## 使用工具

1. 准备一个可访问的 MCP Streamable HTTP 服务。
2. 在管理台“MCP 服务器”中添加地址，发现工具并勾选允许调用的工具。
3. 保存后新开一次语音会话，说出对应任务。

没有配置工具时仍可普通对话。控制硬件或业务系统，需要相应服务实际提供并授权该工具。

## 遇到问题

| 现象 | 先做什么 |
| --- | --- |
| 服务端不可达 | 查看服务端窗口是否仍在运行 |
| 服务端待配置 | 在管理台补齐当前模式的凭据 |
| 听不到唤醒 | 确认没有暂停监听，检查 Windows 默认麦克风 |
| 没有声音 | 检查默认输出设备、音量和托盘错误 |
| 模型连接失败 | 使用管理台连接测试，检查账号权限与网络 |

进一步排查、接入 Windows 音量工具和自定义模型，请看 [详细运行指南](运行指南.md)。
