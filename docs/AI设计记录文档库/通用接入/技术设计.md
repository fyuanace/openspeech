## 外部业务接口

- 接入项目可订阅最终识别文本及回复状态，延续原有文本接入方向。
- 对话模型产生业务请求时，由接入方将请求映射为项目已有业务操作。
- 事件草案包含事件 ID、设备 ID、会话 ID、轮次 ID、类型和载荷。
- 业务请求和执行结果通过独立请求 ID 关联，接入方按 ID 去重。
- 重连补发、结果过期及目标项目选择需在正式契约中明确。
- 端间音频协议集中记录在[端间协议与会话](../跨模块设计/端间协议与会话.md)。

## 验证计划

- 示例客户端分别验证识别文本订阅和业务请求结果关联。
- 模拟重复或迟到消息，检查业务操作不会被重复执行。
- 对接 Findtools 时使用测试实例，命令与亮灯规则由 Findtools 设计确定。

## 重要设计变更

- CHG-001，2026-11-04，保留文本事件并增加对话业务请求与结果关联，以支持语音回复闭环。
