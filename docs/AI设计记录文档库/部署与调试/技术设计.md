## 独立运行

- 设备端与服务端各有启动入口和配置，首版可在同一 Windows 10 电脑运行。
- 设备端连接可配置的服务端地址，服务端配置 STT、TTS 和 LLM 提供方。
- 路径相对 voice 或显式配置的数据目录解析，部署脚本调用各端独立入口。
- 本地模型的依赖和资源按适配器管理，在线提供方连接在服务端建立。
- 模型密钥通过本机私有配置加载，文档及常规日志只记录提供方名称和状态。

## 联调方案

| 层次 | 验证内容 |
| --- | --- |
| 音频 | Windows 麦克风、输出设备及唤醒连续音频 |
| 协议 | 模拟设备发送音频、结束和取消，验证回复关联 |
| 模型 | 豆包 STT、DeepSeek LLM、待选 TTS 的独立调用 |
| 闭环 | 连说唤醒词与内容，听到对应回复 |
| 业务 | 测试 Findtools 接口和模拟灯光执行 |

- 对断网、模型超时和设备重启分别验证错误与恢复。
- CPU、内存、音频积压及回复延迟需实测，指标待确定。
- 树莓派和 ESP32 后续单独适配和验收。
