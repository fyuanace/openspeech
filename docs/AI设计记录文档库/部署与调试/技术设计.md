## 独立运行

- 设备端与服务端各有启动入口和配置，首版可在同一 Windows 10 电脑运行。
- 设备端连接可配置的服务端地址，服务端选择 S2S 或串联模式并配置相应提供方。
- 路径相对项目根目录或显式配置的数据目录解析，部署脚本调用各端独立入口。
- 本地模型的依赖和资源按适配器管理，在线提供方连接在服务端建立。
- 模型密钥通过本机私有配置加载，文档及常规日志只记录提供方名称和状态。

## 当前入口与验证

- Python 3.12 独立虚拟环境，依赖快照见根目录 `requirements-lock.txt`。
- 安装和部署实现位于 `scripts/`。根目录 `deploy.cmd` 准备环境并启动服务端；`setup.cmd` 和 `setup.ps1` 保留仅准备环境的兼容入口。
- 默认监听 localhost 8765，平台 token 自动生成在被忽略的本地配置中。
- 项目使用独立 Git 仓库，远程为 [fyuanace/openspeech](https://github.com/fyuanace/openspeech)，默认分支为 `main`。Findtools 不再记录语音子模块指针。

- 独立服务进程的 HTTP 健康检查、鉴权能力接口及缺失凭据错误路径通过。
- 真实人声、真实云端调用、树莓派、ESP32 以及 Findtools 业务联调待验证。
- 具体命令见[运行指南](../../运行指南.md)。
- S2S 仅检查百炼 API Key 和业务空间地址，串联模式检查豆包和 DeepSeek。健康状态只表示配置是否齐全，不表示账号授权和模型效果已验证。
- 本地回环集成测试实际运行设备客户端、平台服务及模拟千问 WebSocket，检查分片顺序、回复流与断线后关闭上游；不访问云端。

## 一键部署实现

| 内容 | 实现 |
| --- | --- |
| 环境准备 | `scripts/setup.ps1`，定位项目根目录，创建或复用 `.venv/`，要求 Python 3.12 x64 |
| 依赖安装 | 安装 `requirements-lock.txt`，再以 `--no-deps --editable` 安装本项目，避免重新解析并升级运行依赖 |
| 配置初始化 | 调用现有 `init-config`，仅在本地配置不存在时生成；不覆盖已有 token |
| 模型资源 | 复用 `scripts/download_model.py` 的临时目录下载与完成后移动逻辑；`-ServerOnly` 跳过下载 |
| 部署编排 | `scripts/deploy.ps1` 检查端口和项目设备进程，调用环境准备，再以前台命令启动服务端 |
| 退出方式 | 服务端使用 `Ctrl+C`；设备端由现有托盘管理，不增加系统服务或后台进程管理机制 |
| 参数 | `-Python` 指定基础解释器，`-PrepareOnly` 不启动服务，`-ServerOnly` 不下载设备模型 |

- 普通部署使用已构建的 `voice_platform/admin_ui/`，不引入 Node.js 安装步骤。
- 设备端由用户在网页配置完成后启动。部署不访问云端模型，不采音，不运行自动化测试。
- 新脚本只做静态检查；历史功能测试、模型回归和 HTTP 健康检查不代表新脚本已通过部署验收。
- 分机连接、更新、备份与卸载步骤统一维护在 [部署指南](../../部署指南.md)。
- CHG-004，2026-11-05，将安装实现集中至 `scripts/`，增加 Windows 一键部署编排及公开项目资料，保留兼容入口；按用户要求暂不执行脚本。
