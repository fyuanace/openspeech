- 首版 Windows 代码已实现，模拟和本地样本验证通过；真实云端调用、现场效果及与 Findtools 联合部署待验证。
- 设备端与服务端分离，默认优先 S2S，可切换 ASR → LLM → TTS。通用接入及部署与调试提供配套能力，两库使用一致模块名称。
- 对话终端与功能提供方的职责见[总体架构](开发者设计文档库/总体架构设计.md#对话与功能角色)，两类接入契约见[通用接入](开发者设计文档库/通用接入.md#对话与功能独立接入)。
- Findtools 业务动作由接入方维护，语音平台提供通用识别、对话和语音合成能力。
- 正文记录当前有效设计，重要变化在对应文档内记录，Git 保存历史。
