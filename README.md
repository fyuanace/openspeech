# 独立语音平台

- 项目目录为 `voice/`，使用独立 Git 仓库，由 Findtools 通过子模块引用。
- 目标为独立运行、通过通用接口供其他项目接入，并支持与 Findtools 联合部署。
- 架构采用设备端与服务端分离，支持可替换的语音识别、语音合成和对话模型。
- 首版采用 Windows 10 系统麦克风与音频输出、在线豆包 STT 和 DeepSeek LLM，唤醒引擎与 TTS 模型待选。
- 所有终端均以一语即达为验收要求。当前运行代码和部署入口待实现。

## 阅读与维护

- 从总体设计了解全貌，再按问题进入具体模块。
- 索引只维护查询入口。跨模块边界在总体设计中定义，功能和接口细节在对应模块中维护。
- 讨论涉及模块划分或跨模块接口时，同步更新总体设计及受影响的模块。
- 各设计文档明确标注已确定、拟议、待定和当前实现，代码完成后记录验证结果。
- 开发者指定的技术约束和接口要求写入开发者设计，AI 自主确定的关键实现方案按同名模块写入 AI 设计记录。
